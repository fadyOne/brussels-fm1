# BRUSSELS

Custom firmware for the M-VAVE FM-1 by Piknik Elektronik.

Web installer, emulator & manual: https://brussels.piknikelektronik.com

## Build

```sh
./build.sh
```

Output: `build/felucca.fwsc`.

## Recovery

Keep [M-Flasher](https://github.com/jvitkauskas/m-flasher/releases) or [FM-1-transporter](https://github.com/kurogedelic/FM-1-transporter) on hand when flashing custom firmware.
